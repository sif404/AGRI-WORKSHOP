# AIoT Field Simulator — From Sensor to Smart Harvest Decision

An interactive educational prototype demonstrating how Internet of Things (IoT) sensor data can support agricultural monitoring and smarter field decisions.

## Overview

The simulator presents an AIoT-inspired agricultural workflow, connecting field conditions, sensor signals, and decision-making in a single web experience. It is designed as a visual demonstration for learning and workshops.

## Run locally

This project is a standalone HTML experience.

1. Clone or download this repository.
2. Open `index.html directly in a modern browser.

No build step is required for the standalone page.

## Technologies

- HTML
- CSS
- JavaScript

Educational prototype. It should not be treated as a production agricultural control system or as a substitute for calibrated field sensors and agronomic advice.
